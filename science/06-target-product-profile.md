# Target product profile — NVL-101 (seed)

Living TPP. Numbers are design goals, not specifications.

| Attribute | Goal |
|---|---|
| INN / code | NVL-101 |
| Modality | Non-integrating mRNA-LNP |
| Payload | Human WT TREM2 isoform 1 |
| Indication | Early AD / MCI, amyloid-positive |
| Target cell | CNS microglia / myeloid |
| Route (preferred) | IV infusion |
| Route (acceptable) | CSF (IT or ICM) if IV myeloid exposure fails |
| Dosing interval | TBD from protein half-life; working guess every 4–12 weeks |
| On-target PD | Rise in microglial surface TREM2; CSF sTREM2 movement |
| Clinical Phase 1 primary | Safety (infusion, complement, LFTs, CNS inflammation) |
| Clinical Phase 1 secondary | CSF Aβ/tau, optional PET |
| What success is not | Cognitive superiority in Phase 1 |
| Exclusions | Genomic editors; multi-gene cassettes; stem-cell targeting |
| Presentation | Frozen or 2–8 °C sterile vial, single-use |
| Comparators | TREM2 agonist mAbs and oral agonists; anti-amyloid mAbs as standard of care backdrop |

## Quality targets (research → later GMP)

- Appearance: opalescent, no visible aggregates
- Size 60–100 nm, PDI ≤ 0.2
- RNA integrity ≥ 80%
- Encapsulation ≥ 80%
- Endotoxin and bioburden per parenteral research-grade, then USP at GMP
- Identity: TREM2 CDS confirmed on template and by RT-PCR of residual RNA
